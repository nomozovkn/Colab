## About

This project analyzes Uzbekistan migration data using **UNData** and **OzStat** in Google Colab using Python.  
It focuses on net migration rates, refugee populations, and personal remittances over several years.  
The project demonstrates loading XML data, preprocessing, visualization, and PDF report generation.
